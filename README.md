# رهیاب — ثبت مسیر پیاده‌روی با نقشه آفلاین

## ساخت فایل نصبی (بدون نیاز به کامپیوتر قوی)
1. در github.com یک حساب و یک مخزن (repository) تازه بسازید.
2. فایل zip را باز کنید. **محتویات داخل پوشه rahyab** را با «Add file → Upload files» بکشید و Commit کنید.
   فایل `settings.gradle` باید در صفحه اول مخزن دیده شود.
3. پوشه `.github` مخفی است و شاید آپلود نشود. اگر نشد: «Add file → Create new file»،
   نام را دقیقاً `.github/workflows/build.yml` بنویسید، متن همان فایل را بچسبانید و Commit کنید.
4. برگه **Actions** ← **Build APK** ← **Run workflow**.
5. پس از تیک سبز، وارد همان اجرا شوید و از بخش **Artifacts** فایل `rahyab-apk` را دانلود کنید.
6. zip را باز کنید، `app-debug.apk` را به گوشی ببرید و نصب کنید (اجازه «نصب از منابع ناشناس» لازم است).

اگر ساخت قرمز شد، متن خطا را بفرستید تا اصلاح شود.

روش دیگر: باز کردن پوشه در Android Studio و Build → Build APK(s).

## استفاده
1. قبل از رفتن (با اینترنت): «نقشه آفلاین» ← دانلود نقشه ایران (حدود ۳۰۰ مگابایت)
   یا فایل `.map` را جدا دانلود و از گوشی انتخاب کنید:
   https://download.mapsforge.org/maps/v5/asia/iran.map
2. GPS را روشن کنید و زیر آسمان باز منتظر دقت مناسب بمانید (بار اول ممکن است چند دقیقه طول بکشد).
3. «شروع حرکت»؛ خط نارنجی مسیر شما رسم می‌شود (سبز = مبدأ).
- دکمه «لایه‌ها» نوع نقشه را عوض می‌کند: ماهواره‌ای رایگان (Sentinel-2، دقت ۱۰ متر، فقط استفاده غیرتجاری؛
  جاهایی که آنلاین دیده‌اید آفلاین هم می‌ماند)، فایل MBTiles تصویری، یا نقشه خیابانی آفلاین.
- چرخش نقشه با دو انگشت؛ لمس قطب‌نما: شمال بالا / جهت حرکت بالا.
- لمس پین هر نقطه: مختصات، راهنمایی مستقیم تا نقطه، و ارسال.
- دکمه آدمک/خودرو حالت حرکت را عوض می‌کند. حالت ماشین: سرعت‌سنج و هشدار دوربین و سرعت‌گیر
  (داده OpenStreetMap و گزارش‌های شما؛ کامل نیست). ترافیک زنده ندارد. هشدارها فقط وقتی برنامه روی صفحه است.
4. «ذخیره مختصات» مختصات همان لحظه را با نام دلخواه ذخیره می‌کند.
5. «پایان حرکت»؛ نقطه قرمز مقصد است.
6. «نقاط» و «مسیرها»: نمایش، کپی، ارسال، حذف و خروجی CSV / GPX.

## نکات مهم برای جنگل
- در تنظیمات گوشی، محدودیت باتری این برنامه را بردارید (Battery → Unrestricted)،
  به‌خصوص در شیائومی، سامسونگ و هواوی؛ وگرنه ثبت مسیر با صفحه خاموش ممکن است قطع شود.
- صفحه تا وقتی برنامه جلوی چشم است روشن می‌ماند؛ برای صرفه‌جویی باتری دکمه خاموش کردن صفحه را بزنید.
- زیر درختان انبوه دقت GPS کم می‌شود؛ نقاط با خطای بیش از ۳۵ متر در خط ثبت نمی‌شوند.
- فقط به این برنامه تکیه نکنید: پاوربانک ببرید و مسیر برگشت را به کسی اطلاع دهید.
- هر ساخت تازه در GitHub امضای متفاوتی دارد؛ برای نصب نسخه جدید باید قبلی حذف شود،
  پس اول از نقاط و مسیرها خروجی بگیرید.
